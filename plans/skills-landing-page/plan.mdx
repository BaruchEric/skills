# Skills for coding agents — landing page

Build a single, static landing page that showcases the ten skills in this repo
as a scannable catalog: a hero with the one-line install command and a grid of
skill cards, one per `/command`. The aesthetic is **dark dev-tool** — near-black
background, hairline borders, monospace command names, and a neon-mint accent on
calls-to-action and card hover.

**Done means:** `bun run build` produces a static `dist/` with no type errors; all
ten cards render from a single typed data array and link to their skill README;
the page is responsive (3-col → 1-col) with a working light/dark toggle; and both
themes pass a contrast check. The product decisions are settled — see **Decisions**
below.

</RichText>

<RichText id="h-stack">

### Stack decision

</RichText>

<Callout id="callout-stack" tone="decision">

Build with **Vite + React + TypeScript** and plain **CSS variables** — no UI
framework. React gives one clean `SkillCard` component and a data-driven grid;
Vite ships a tiny static `dist/` with no runtime dependencies; CSS variables carry
the dark dev-tool theme without pulling in Tailwind. The ten skills live in one
typed `skills.ts` array, so adding a skill is a one-line change rather than new
markup.

</Callout>

### Design tokens — dark dev-tool

The whole aesthetic lives in a handful of CSS variables. Mono command names, a
near-black surface stack, and a single neon-mint accent for CTAs and hover. A
`[data-theme="light"]` block overrides the same variables, so the toggle is a
one-attribute switch.

</RichText>

<RichText id="h-build">

### Build and deploy

Ships to **GitHub Pages**: `vite build` emits a static `dist/`, published with
`gh-pages -d dist` (or a Pages Action on push to `main`). Set `base: '/skills/'`
in `vite.config.ts` so assets and the `/media/` images resolve under the
project-pages path.

</RichText>

<RichText id="h-decisions">

### Decisions

</RichText>

<Callout id="callout-decisions" tone="decision">

Settled for the first cut:

- **Deploy:** GitHub Pages — `gh-pages -d dist`, `base: '/skills/'`.
- **Card click:** each card links to the skill's `README.md` on GitHub.
- **Theme:** light/dark toggle, dark by default.
- **Media:** thumbnails on the two skills that have them (`/visual-plan`, `/visual-recap`); the rest stay text-only.

</Callout>
